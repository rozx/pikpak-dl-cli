# 共有テキストのコピー

テキスト全体を一度にコピーし、リンクとパスコードが同じスナップショットに含まれるようにしてください。以下は形式を示すための合成例で、実在するリソースではありません。

```text
链接：https://mypikpak.com/s/synthetic-one
密码：demo
```

パスコードのラベルは、PikPak の各言語のクライアントがコピーするときの表記と、よく使われる同義語に対応しています。`パスワード`、`パスコード`、`暗証番号`、`Password`、`Pass code`、`提取码`、`密码`、`비밀번호`、`Kata sandi` などです。ラベルの後には `:`、`：`、`=`、空白、または「は」を続けられます。ただし英語など単語を空白で区切る言語のラベルでは、コロン、等号、または `is` が必要です（`Password: demo`、`the password is demo`）。パスコードを括弧や引用符で囲んでもかまいません。行末がコロンの場合は、次の行にパスコードだけを書くこともできます。ただしその行が最後の行であるか、後ろに空行が続く場合に限ります（そうでない場合はテンプレートのファイル名の可能性があるため、パスコードとして扱いません）。解凍パスワード、アカウントやログインのパスワード、Vault の共有キー、Wi-Fi のパスワードはパスコードとして扱いません。

PikPak のウェブ版を日本語で使っている場合、コピーされるテキストは「パスワード:」の後が空になっています（ウェブ版の日本語テンプレートの不具合です）。この場合はパスコードなしの共有として受け付け、「パスコードが必要」と表示されるので、パスコードを書き足してからもう一度コピーするか貼り付けてください。

リンク内で明示された `pwd`、`password`、`passcode`、`pass_code` パラメーターにも対応しています。パスコードのない共有はリンクだけをコピーすれば十分です。実際にパスコードがない場合と誤っている場合には、それぞれ `PASS_CODE_EMPTY`、`PASS_CODE_ERROR` が返ることを確認しています。これらは新しいテキスト全体を待つべき状態であり、アカウント全体の失効とは見なしません。

複数の共有は、それぞれ別の行や段落に分けてかまいません。ただし、各パスコードがどのリンクのものかを明確に対応付けられる必要があります。区別できない複数のリンクの後にパスコードが一つだけある場合は推測しないので、一つずつコピーしてください。類似したドメイン、PikPak のほかのページ、パスコード単独、普通のテキストではタスクを作成しません。クリップボードの元の内容はログにもデータベースにも書き込みません。

タスク ID 付きの受け付け確認が表示されて初めて、情報とリクエストが保存されたことになります。一度のコピーで一部の共有だけ保存に失敗した場合、確認済みの共有はそのまま残り、監視は未確認の部分だけを再試行します。クリップボードは現在の内容のスナップショットです。素早くコピーを続けると、まだ読み取っていない内容が上書きされることがあり、変更カウンターから履歴を復元することはできません。確認が表示されなかった場合は、もう一度コピーしてください。

同じテキストを再度コピーすると、差分スキャンを開始できます。クリップボードを変えずにおいても繰り返しスキャンすることはなく、リモートの共有の更新を定期的に監視することもありません。完了して変更のないバージョンは、ローカルの結果を移動していても自動で再ダウンロードしません。同じ名前の新しいバージョンが現れても、以前の結果は残します。失敗の上限に達したら、監視を停止して `retry <タスクID>` で回数制限付きの試行を新たに開始してください。共有をコピーしても、ファイルの再試行回数はリセットされません。

既定のダウンロード先を変更すると、新しい共有と、ローカルにまだ何もない共有は新しいフォルダを使います。ダウンロードを開始済み、または完了済みの共有では、以降のファイルも元のフォルダを使い続けます。`cancel` はリソースとキャンセルの印を残します。古いテキストがクリップボードに残っていても、キャンセルした共有が再び始まることはありません。

全画面インターフェースではクリップボード監視が既定でオンになっており、設定ページでオフにできます。オフにした場合は `a` で共有テキストを貼り付けます。貼り付け欄とクリップボードは同じ解析規則を使います。クリップボードの読み取りは子プロセスに分離されているため、障害が起きてもダウンロードを妨げません。macOS ではシステムのクリップボードのスナップショットを読み、Windows ではシステムの PowerShell で読み取り、Linux では `wl-paste`（Wayland）または `xclip`、`xsel`（X11）を呼び出します。利用できるクリップボードがない場合、画面には監視の異常が表示されますが、貼り付けは引き続き使えます。
