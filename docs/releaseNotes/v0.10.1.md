# PikPak DL CLI v0.10.1

发布日期：2026-10-29

新复制的分享不再排在下载队列后面：接收后立即确认链接与提取码并扫描文件清单，下载时只转存和下载。

## 改进

- **队列暂停时照常扫描**：暂停队列只停止转存与下载，新接收的分享照常扫描，继续队列后直接转存并下载。本地磁盘写满、下载目录不可用、流量不足导致的暂停也不影响扫描；登录失效、权限不足、任务库不可写或账号被限流时，扫描等问题解决后再进行。全屏界面中，队列暂停时扫描中的分享仍显示转动的图标，暂停中的文件图标保持静止。

## 修复

- **接收分享后立即扫描**：以前扫描和下载排在同一个队列里，同时下载数为 1 时，有文件正在下载，新复制的分享要等它下载完才开始扫描。链接失效、缺少提取码或提取码错误要等轮到它下载时才显示。现在分享接收后马上确认链接与提取码并扫描，文件清单或访问错误随即出现在列表中，之后再按队列逐个转存、下载。扫描与下载同时进行，不占用同时下载的名额，正在下载的文件不受影响。暂停或取消正在扫描的分享只停止它的扫描，其他文件继续下载。

## 升级说明

直接替换可执行文件即可。任务库结构不变，不需要迁移或重新登录。

队列处于暂停状态时，升级后启动会扫描尚未扫描的分享，但不会开始转存或下载。

## 已知问题与待验收

- 接收后立即扫描、队列暂停期间扫描与停止扫描已由自动测试覆盖（Windows 上使用真实文件系统，macOS 与 Linux 由 CI 覆盖），尚未用真实 PikPak 账号在全屏界面中实机验证。
- 扫描与转存现在可能同时发出请求，账号限流可能比以前更早出现；限流期间扫描与下载都按服务端要求等待。
- v0.10.0、v0.9.2、v0.9.1 与 v0.8.1 列出的待验收项仍然有效。
