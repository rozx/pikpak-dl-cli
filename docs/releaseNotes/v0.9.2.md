# PikPak DL CLI v0.9.2

发布日期：2026-10-25

提取码缺失或错误时，分享不再一直显示“扫描中”，可以在界面里直接补填提取码；也能识别只有链接和一行提取码的分享文本。

## 改进

- **在界面中补填提取码**：分享因提取码缺失或错误而停下时，选中该分享按 Enter 打开提取码输入框，提交后立即重新扫描。按键提示中的 Enter 会相应显示为“提取码”。提取码只能是 1 到 32 位字母或数字，格式不对时在输入框内说明。
- **识别单独一行的提取码**：整段文本只有一行链接和一行提取码（中间可以有空行）时，即使没有“提取码：”之类的标注，也能识别。其他没有标注的文字仍不当成提取码。

## 修复

- **扫描失败不再显示为“扫描中”**：提取码被拒绝、分享已失效或扫描多次失败时，分享行以红色显示原因，不再显示“扫描中”和动态图标。提取码问题分为“分享需要提取码”和“提取码错误”两种，分别显示。

## 升级说明

直接替换可执行文件即可。任务库结构不变，不需要迁移或重新登录。

升级前已经因提取码停下的分享仍显示“分享需要提取码，或提取码不正确”，同样可以按 Enter 补填提取码。

## 已知问题与待验收

- 提取码输入框尚未在真实终端中手动演练，目前只经过自动化界面测试。
- 之后单独复制的提取码仍不会自动配对到等待中的分享，需要按 Enter 输入，或重新复制包含链接和提取码的完整文本。
- v0.9.1 与 v0.8.1 列出的待验收项仍然有效。
