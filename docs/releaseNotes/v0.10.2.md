# PikPak DL CLI v0.10.2

发布日期：2026-11-21

修复浏览器授权无法完成的问题：PikPak 授权页改版后不再列出任何权限，“授权”按钮无法点击。

## 修复

- **授权页没有权限、无法授权**：PikPak 授权页现在只显示应用在授权请求中列出的权限。以前的版本只请求登录基础范围，授权页的权限列表是空的，“授权”按钮呈灰色，首次登录、`login --force` 与账号页的重新授权都无法完成。现在程序在授权请求中列出账号信息（`account`）、管理文件（`files:manage`）、分享（`share`）与云下载（`cloud_download`），授权页逐项显示这些权限，全部勾选后即可授权。授权返回后照常核对必需权限，缺少时提示重新授权。

## 升级说明

直接替换可执行文件即可。任务库结构不变，不需要迁移。已登录且会话有效时不需要重新登录；之前因授权页无法授权而没有登录成功的，替换后重新启动或运行 `pikpak-dl-cli login` 即可。

## 已知问题与待验收

- 新的授权请求已由自动测试覆盖，尚未用真实 PikPak 账号实机验证授权页的显示与授权结果。
- 之前已注册的本机 OAuth 客户端会继续使用，不重新注册。
- v0.10.1、v0.10.0、v0.9.2、v0.9.1 与 v0.8.1 列出的待验收项仍然有效。
