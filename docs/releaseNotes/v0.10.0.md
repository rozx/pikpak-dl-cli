# PikPak DL CLI v0.10.0

发布日期：2026-10-25

已取消的任务可以从列表中删除；从剪贴板接收分享时有明确的提示；事件区可以展开查看更多记录；启动时不再接收剪贴板里遗留的旧文本。

## 新功能

- **删除已取消的任务**：选中已取消的文件或分享按 `x`，确认后释放它的云端副本，删除未完成的临时文件（`.pikpak-part`）和任务记录，任务从列表中消失。云盘里已经没有副本时只删除记录；扫描失败后取消、没有任何文件的分享也可以删除。临时文件与任务库记录的身份不符或所在磁盘不可用时，保留记录并在事件区说明原因。已下载完成的本地文件始终保留。
- **展开或收起事件区**：主面板按 `l` 切换。展开时显示更多最近事件（最多约半个窗口高），再按一次恢复为 3 条。事件区上方的分隔线右侧会提示“l 展开日志”或“l 收起日志”。

## 改进

- **剪贴板接收的反馈**：从剪贴板接收到分享时，事件区写明“已从剪贴板接收分享…”，并尝试把终端窗口带到前台：Windows 上激活 Windows Terminal 或控制台窗口，macOS 上激活启动程序的终端应用，Linux X11 下安装了 `xdotool` 时激活终端窗口。没有可见窗口的宿主（如编辑器内置终端）和 Wayland 下只在事件区提示，不会让当前窗口失去焦点。手动粘贴和 `watch` 不切换窗口。
- **全部释放包括已取消的任务**：`X` 现在同时处理已完成与已取消的任务，仍在进行中的任务不受影响。确认框写明这一范围。

## 修复

- **启动时不再接收旧的剪贴板内容**：程序启动时、或在设置页重新开启剪贴板监听时，剪贴板里已有的文本只作为起点，不再被当成新的复制而新建任务或重新扫描。之后的复制照常接收，复制相同的文本也算。需要接收启动前复制的内容时，重新复制一次或按 `a` 粘贴。

## 升级说明

直接替换可执行文件即可。任务库结构不变，不需要迁移或重新登录。

升级后第一次启动时，剪贴板里已有的分享文本不会被接收；如需添加，请重新复制。

## 已知问题与待验收

- 窗口前置只在 Claude 桌面应用的内置终端中验证过“没有可见窗口时跳过”；Windows Terminal、传统控制台窗口、macOS 终端应用与 Linux X11 下的实际前置效果尚未实机验证。Windows 的前台锁可能在某些情况下只让任务栏图标闪烁。
- 删除已取消任务时的临时文件删除已在 Windows 的真实文件系统上测试；macOS 与 Linux 由 CI 覆盖。
- v0.9.2、v0.9.1 与 v0.8.1 列出的待验收项仍然有效。
